## Três perguntas que eu gosto de responder

| Pergunta | Onde ela mora |
| --- | --- |
| Esse lote vai para o pote, espera ou é descartado? | BrineLog |
| Essa transação parece fraude, e por quê? | Detecção de fraudes |
| Esse orçamento fecha, mesmo falado em voz alta? | API de orçamento com voz |

O resto da trilha fecha o ciclo. O número precisa aparecer num painel, e o serviço precisa existir fora da minha máquina.

## Em destaque

### BrineLog

Uma API que olha para um lote de fermentação e escolhe o destino: pote, espera ou descarte. O Spring Boot carrega a regra, dividida em Strategy, Facade e Singleton, para a decisão não ficar espalhada pelo código.

[Abrir o BrineLog](https://github.com/sir-devtech/brinelog-bootcampitau)

### Orçamento com voz

API de orçamento que escuta. Spring Boot com Spring AI, no projeto final do bootcamp Itaú. A ideia é simples de dizer e chata de fazer bem: a pessoa fala o que gastou, e o serviço organiza isso como dado.

[Abrir a API](https://github.com/sir-devtech/DIO-Spring-Boot-Final-Project-Itau)

### Fraude que se explica

Detecção de fraude em transações bancárias, no bootcamp Afya Dados da DIO. Random Forest para classificar, SMOTE para o desbalanceamento e SHAP para o modelo não só apontar o risco, mas mostrar o que pesou na decisão.

[Abrir o projeto](https://github.com/sir-devtech/Dio-Detec-o-de-Fraudes)

### Vendas na tela

Dois painéis no Power BI, do desafio DIO / Universia, e um terceiro com cara de produto.

- [Dashboard de vendas](https://github.com/sir-devtech/dashboard-vendas-powerbi): três páginas, com vendas, lucro por país e mapas por segmento.
- [Relatório gerencial](https://github.com/sir-devtech/relatorio-gerencial-vendas-powerbi): duas páginas, com KPIs, bookmarks, botões e navegação.
- [Porsche Sales Intelligence](https://github.com/sir-devtech/Dashboard-Porche-DIO-IA): leitura de vendas com o recorte da marca.

### Nuvem, numa linha só

Lambda com S3, Step Functions, CloudFormation e uma aplicação serverless no Azure. Aqui a nuvem não é o assunto principal. É o lugar onde o resto passa a rodar.
